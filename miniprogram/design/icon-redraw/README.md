# 羽翼徽记 · 六边形图标（矢量重绘）

从裁剪截图 `source.png`（205×187）重绘的矢量图标：只保留六边形结构与内部羽翼，去掉迷彩背景，透明底。
两套配色共用同一份羽翼几何：**暗金版**（还原原图）+ **彩色版**（幻彩面板 + 淡紫羽翼，参考 `color_ref.png`）。

## 结构（512 画布，中心 256,256，尖顶六边形）

| 层 | 半径 | 说明 |
| --- | --- | --- |
| 外倒角 `#bevel` | R 240 | 深棕金属边，左上受光、右下压暗 |
| 灰环 `#ring` | R 215 → 196 | 唯一的高亮结构线，宽度约占整图 3.7% |
| 内面板 `#face` | R 196 | 暗棕面板，左上偏亮 + 边缘暗角 |
| 羽翼 `#wing1..3` | — | 象牙白，3 块独立板片（原图就有 1.5px 缝隙，保留） |

比例取自实测：原图外接圆 77px、灰环 69–63px、内面 63px，按 `240/77` 等比映射。

**彩色版的结构差别**：外廓 240 和内面 196 不变，只把 215–196 这段环带拆成
「外段并进炭黑边框 + 内段 16 单位做珠光细边」（`R_RIM = 212`），对齐参考图"厚框 + 一条细高光"的关系。

## 还原度

用 `tools/compare.py` + `tools/qa.py` 在 205×187 原图坐标系下量过暗金版：

- 羽翼白色掩膜 IoU **0.937**，外框与重心偏差 ≤0.4px；
- 分层中位色差：倒角 0.7 / 灰环 1.3 / 面板 2.0 / 羽翼 2.3（0–255 通道均值）。

差异主要来自两点：原图是压缩截图，边缘有 1–2px 模糊，重绘是硬边；羽翼细缝在原图已接近 1px，描摹后按轮廓取中。
彩色版没有原图可比，按参考模板的色相分布（左上薄荷 / 正上淡紫 / 右上粉 / 底部奶油）对位。

## 怎么用

- 小程序里用 `icon_128.png` / `icon_color_128.png`（或 256）当 `<image>` 源即可；微信 `<image>` 对 SVG 支持不稳，别直接塞 SVG。
- 需要字体图标、Canvas 或导出其它尺寸，用对应 `.svg` 转，几何矢量无损。
- 建议最小使用尺寸 **96px**：再小（64px）三条斜缝会糊成一片，需要小尺寸版本的话，得单独做一版减笔画的光学修正，而不是缩这张。
- 若要把 `design/` 留在小程序包里，记得在 `project.config.json` 的 `packOptions.ignore` 里排除，避免占主包体积（已配置 `design` 目录忽略）。

## 重出流程

```powershell
$py = "C:\Users\wbq\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
& $py design\icon-redraw\tools\trace.py        # 描摹羽翼 -> emblem_debug.json
& $py design\icon-redraw\tools\build_icon2.py  # 暗金版：SVG + 各尺寸 PNG
& $py design\icon-redraw\tools\build_color.py  # 彩色版：SVG + 各尺寸 PNG
& $py design\icon-redraw\tools\color_qa.py     # 彩色版对照图
& $py design\icon-redraw\tools\verify_svg.py   # 校验 XML/渐变引用/路径参数
& $py design\icon-redraw\tools\compare.py      # 暗金版与原图逐像素比对
```

调形状改 `trace.py` 的 `EPS`（抽稀容差，越小越贴边、节点越多）和 `CORNER`（转角阈值，越小越多尖点）；
调颜色改 `build_icon2.py` / `build_color.py` 里的 `GRADS`，几何改 `R_OUT / R_RING_OUT / R_RING_IN`（彩色版细边半径在 `build_color.py` 的 `R_RIM`）。

## 已知限制

- 源图仅 205×187，羽翼是“描摹还原”而非原始设计稿，端部尖角有 ±1px 级偏差。
- 原图内面板上的斜向肌理是背景透出来的，未复刻，保持面板干净。
- 彩色版的幻彩面板是用多层径向渐变叠出来的（SVG 无锥形渐变），色相分布是近似，不是逐像素复刻模板。
- 本机沙箱内 Chrome 无法启动，PNG 由脚本内的超采样填充器渲染（与 SVG 同一份几何数据），不是浏览器渲染结果。
