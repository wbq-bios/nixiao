# 羁绊徽记 · 彩色版 / 灰色版（22 枚批量重绘）

来源：`碧血营.zip`（S3 赛季羁绊图标，22 张 121px 徽记截图）。
每枚图标输出两套配色：**彩色版**（幻彩面板 + 淡紫徽记）和**灰色版**（同结构去色）。

## 文件

| 路径 | 内容 |
| --- | --- |
| `src/` | 从 zip 解出的 22 张原图（未改动） |
| `out/color/<名>.svg` | 彩色版矢量母版，512×512 |
| `out/color/<名>_512 / _256 / _128 / _64.png` | 彩色版位图，透明底 |
| `out/gray/…` | 灰色版，命名同上 |
| `preview/sheet_color.png` / `sheet_gray.png` | 22 枚总览（带名字） |
| `report.json` | 每枚的圆心、片段数、孔洞数 |
| `tools/batch_bonds.py` | 批处理脚本（定位 → 描摹 → 双配色渲染） |
| `tools/contact_sheet.py` | 生成总览图 |

## 几何从哪来

22 枚徽记的外框完全一致：灰环外接框 121×139（外接圆约 69.5px，含倒角 77px），只是裁剪偏移不同。
所以沿用白帝城那套几何：512 画布、中心 256,256、外廓 R240、珠光边 R212、面 R196，
用各图自己的灰环中心做定位（`find_badge`：只在 bbox≈121×139 的灰环连通域里选，避免截到旁边的文字或半个图标）。

## 描摹流程

1. 原图放大 4 倍（Lanczos）再二值化——1x 会把 1px 的护手、枪杆描成锯齿，抽稀后整块细节消失。
2. 阈值用**面内亮度 Otsu 自适应**（实测落在 136~140），写死 150 会把偏暗的白整块切掉。
3. 掩膜 5×5 最大值滤波外扩约 0.5 源像素，补回"像素中心描边"造成的整体缩水。
4. Moore 邻域描边 → RDP（容差 0.30 源像素）→ 直接输出直线多边形，不再做二次曲线平滑：
   平滑会让每个片段缩进约 0.5px，多片段图标（如破军 8 片）的缝隙被撑大一倍，护手会和剑身断开。
5. 孔洞单独描边，和外轮廓同属一条 `fill-rule="evenodd"` 路径；片段之间取并集，不参与异或
   （异或会把相邻重叠处抠掉，同样踩过）。

## 两套配色

**彩色版**（取自 `碧血营` 参考图的幻彩关系）

| 层 | 值 |
| --- | --- |
| 边框 | `#413D3E → #353132 → #292627` |
| 珠光边 | `#FFFFFF → #FFFDF6 → #FFF9E6` |
| 面板底 | 中心 `#FFFFFF`，边缘 `#FFF3C8` |
| 薄荷/淡紫/粉/粉紫/奶油 | `#CEFBE9` / `#DBCBFF` / `#FBD4F4` / `#FFDEF9` / `#FFF4CB`（径向叠加） |
| 徽记 | `#CEA0F0 → #BC8CE7 → #A877D9` |

**灰色版**：同结构去色，浅灰珠光边 + 灰面板（`#F0F0F0 → #D9D9D9`）+ 中灰徽记（`#A6A6A6 → #8C8C8C`）。
徽记比面板深，保持和彩色版一致的正负形关系，缩到 64px 也还能读。

## 质量说明

- 源图只有 121px 徽记，细节（护手细线、羽毛、眼睛）是"描摹还原"，不是原设计稿；**512 看会有简化感，128 以下基本无差**。
- 影响最大的是 `破军`（双剑，原件被暗线分成 8 片，缝隙在原图里靠模糊连成一片）和 `碧血营`（鸟+枪，细节多）。
- 统一建议最小使用尺寸 **96px**；64px 时细缝会糊。
