## 1. 产品定位（已定）

- 服务《逆水寒手游》「逆水侠棋」自走棋玩法的微信小程序工具，参照金铲小助手的功能形态。
- 定位：**赛前备课 · 局间快查 · 赛后复盘**（游戏无阵容码接口、小程序无法悬浮，故不做对局内实时辅助）。
- 名称：**逆水小助手**（备用：侠棋小助手；页面保留非官方免责声明）。
- 数据策略：首版只录当前赛季，历史赛季归档可查；所有数据带 `season` 字段云端热更新。
- 内容冷启动：自己整理录入，不依赖 UGC。
- 变现预留：信息流 banner 广告位已留（首页 + 图鉴），正式版可配置开关。

## 2. 设计语言（finesse h5 · morph A-app-shell）

- **配色**：宣纸浅色系——暖米白底 `#F3EFE6`（带 4.5% 绢面颗粒）、墨色文字 `#26221A`、古铜金强调 `#A98643`。棋子费用五阶色：1 灰 / 2 绿 / 3 蓝 / 4 紫 / 5 金。
- **字体**：标题楷体（Kaiti SC），正文系统黑体；印章式单字头像（无立绘素材，规避版权）。
- **框架**：锁 body + `.view` 各自滚动；悬浮胶囊 TabBar（带文字）；push 层详情（右滑入）；底部弹层（拖把点 + 点遮罩关）；真实时钟状态栏；安全区 `env()` 全覆盖；`prefers-reduced-motion` 终态。
- **动效**：仅反馈级——列表错落浮入（60ms 阶梯）、按压缩放（`.96`）、push/sheet 滑入（`cubic-bezier(.32,.86,.28,1)`）、滑块平移（380ms）。

## 3. 信息架构（5 Tab）

```
首页      赛季入口行→切换弹层 · 今日热荐卡 · 4 快捷入口 · 刷牌概率表 · 广告位 · 更新志
阵容      排序(强度/热度/口碑/最新) + 筛选(全部/彩色羁绊/84/95) + 赞踩 → 详情
摆棋      赛季标识 · 撤销/重置/示例 · 4×7=28 格蜂窝棋盘 · 点格选棋/点棋子设置 · 羁绊实时推算 · 保存到我的
图鉴      棋子/羁绊/装备/心悟 四段 + 搜索 + 费用筛选 · 详情互跳 · 广告位
我的      赛季入口行 + 全部阵容|当前赛季 滑块 → 我的阵容(推演存档) / 我的收藏(☆收藏) + 关于
```

## 4. 各模块交互规格（正式工程照此实现）

### 4.1 阵容库（阵容推荐）
- 卡片：8 格头像条（费用色描边 + 主 C 橙角标）→ 名字 + S/A/B 徽章 + `95`/`84` 金徽 + ✦彩色羁绊 → 羁绊胶囊（层数）→ 主C/人口/热度/更新时间 → **赞/踩**（单人一票可改不可叠加，净分计入「口碑」排序）。
- 详情页：等级徽 + 标签行 → 羁绊胶囊（图标+层数徽章，彩色鎏金）→ 前排/后排方形头像格（星级/C角/装备小格/名称）→ 四列数据（平均排名/出场率/登顶率/前四率，演示数据）→ 核心装备 → 心悟选择序 → 运营节奏时间线 → 对局提示 → 生成分享卡片（弹层预览）。
- ☆ 收藏：记录收藏时所在赛季。

### 4.2 摆棋推演（核心功能）
- **棋盘固定 4 排 × 7 列 = 28 格蜂窝**全量显示（底排前排）；人口 = 棋盘实时计数（无档位选择）。
- 点空格 → **选棋弹窗**（近全屏）：标题+排号位号+当前、搜索框+N 位计数、费用 chips、全部职业/全部羁绊双下拉、六列头像网格（费用角标、已上阵绿框）、点选即落位。
- 点棋子 → **棋子设置弹窗**（居中卡片）：头像+费用+职业羁绊标签、**主C 开关**（全局唯一）、星级 −★＋（1-3）、装备三槽（空槽点开装备选择面板按品阶选，已填点击卸下）、**棋子详解**（只读描述）、移除英雄/完成设置。
- 长按 300ms 拖拽：幽灵棋子 1:1 跟手，顶部顶出红色「拖到此处移除」热区，拖到其他格金色高亮换位；8px 阈值防误拖；`pointercancel` 纯取消；拖拽期锁滚动。
- 撤销栈 30 步（选棋/换位/星级/装备/重置均先存快照）；重置可撤销；示例一键摆满五辅阵容。
- 羁绊实时推算：按数量排序、`N/下一档` 进度、未激活半透明、彩色鎏金、满档显示「N 满」。
- **保存到我的**：存完整棋盘快照（board/stars/items/main + season）。

### 4.3 我的
- 赛季入口行（当前赛季名 + 切换赛季›→弹层：选中行米黄底金边+「当前赛季」，其余「切换」）。
- 「全部阵容 | 当前赛季」两段滑块（米黄 thumb 平移），过滤下方两分区。
- **我的阵容**：摆棋推演存档卡（名字+赛季标签+棋子条+枚数/费用/主C+载入摆棋+删除）。
- **我的收藏**：阵容推荐☆收藏卡（名+等级+赛季标签+棋子条+羁绊+删除），点卡开详情。

## 7. 正式工程落地清单（下一步）

1. **脚手架**：原生小程序 + 微信云开发（云数据库/云函数/云存储），按 §5 建集合，全部带 season。
2. **页面映射**：5 Tab → `pages/home / comps / sim / dex / me`；弹层 → 组件（picker-sheet / unit-modal / season-sheet）；拖拽用 pointer 事件方案平移（长按 300ms + 8px 阈值 + pointercancel）。
3. **设计 Token**：宣纸底/墨字/古铜金/五阶费用色/楷体标题 → `app.wxss` 变量。
4. **内容录入**：按 §5 结构整理当前赛季真实数据（来源：官方公告+社区攻略人工核对）；演示数据即录入模板。
5. **合规**：提审备好备选名「侠棋小助手」；页面保留非官方声明；不用任何游戏立绘。
6. **广告**：信息流 banner 位接 `ad` 组件，后台开关控制。
