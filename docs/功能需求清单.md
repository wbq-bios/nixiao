# 侠棋小程序 · 功能需求清单 v0.1

> 目标：为《逆水寒手游》「逆水侠棋」自走棋玩法做一个微信小程序工具，产品形态参照金铲铲之战的助手类小程序（金铲小助手、铲铲军师、云顶攻略助手等）。
> 调研日期：2026-10-28
> **原型已归档（2026-10-28，v0.13）**：视觉与交互规格全部定稿，见 [原型总结](原型总结.md) 与 [原型快照](../prototype/archive/原型-v0.13-2026-10-28.html)。下文 P0/P1 中除"云端数据基座、全局搜索、D牌概率表(已做)"外均已原型化。

---

## 1. 项目背景与定位

- 逆水侠棋是《逆水寒手游》内置的自走棋（auto-battler）玩法：招募棋子、凑羁绊、升人口，与其他玩家自动对战；棋子均为逆水寒经典 NPC（四大名捕、连云寨、舞阳城魔头等），对玩家有"江湖回忆杀"情怀加成。
- 该玩法有完整的段位与赛季体系，版本更新频繁（2025-07 首次大更新 50 项调整、2025-11 赛季「盈虚化象」、2026 年持续平衡调整与联动棋子），玩家对"查数据、抄阵容"有稳定需求。
- **竞品现状：目前微信生态内没有成型的"逆水侠棋助手"小程序**，玩家只能看 B 站视频和媒体图文攻略，查询类需求没有被满足 → 市场空白。
- 与金铲铲助手的两个关键差异（决定产品边界）：
  1. 金铲铲官方支持「阵容码」游戏内一键导入；**侠棋目前没有发现官方阵容码/导入接口** → 我们不能做"一键导入游戏"，改做"阵容卡片 + 站位图 + 小程序内分享"。
  2. 金铲铲有 App 级助手（如迅游内置"铲铲军师"）可在对局中实时推荐；**微信小程序无法悬浮在游戏画面上** → 定位为"赛前备课、局间快速查阅、赛后复盘"工具，而不是对局内实时助手。

## 2. 参照对象功能盘点（金铲铲类助手在做什么）

| 功能类 | 具体功能 | 对侠棋的适配结论 |
|---|---|---|
| 数据图鉴 | 英雄（棋子）图鉴、羁绊图鉴、装备合成表、强化符文查询 | ✅ 全部适用，是核心 |
| 阵容 | 版本强势阵容排行（Tier List）、阵容详情（构成/装备/符文/运营节奏）、阵容码一键导入 | ✅ 排行与详情适用；阵容码导入 ❌（游戏无此接口） |
| 工具 | 阵容模拟器（拖棋子自动算羁绊）、D 牌概率表、升级经验/利息计算 | ✅ 适用（侠棋同为 1-5 费 + 3 合 1 升星 + 50 金吃利息体系） |
| 内容 | 版本更新公告、攻略资讯聚合 | ✅ 适用 |
| 社区 | 收藏、评论点赞、投稿、开黑组队、战绩查询 | ⚠️ 战绩查询无官方 API，只能做手动记录；社区功能放后期 |
| AI | AI 阵容推荐 / 对局实时推荐（铲铲军师） | ⚠️ 只能做"离线 AI"（输入当前棋子→推荐转型方向），放后期 |

## 3. 逆水侠棋玩法机制速览（决定数据模块怎么建）

### 3.1 棋子
- 费用分 1～5 费，5 费战力最强（例：方承意、无情、韩飞瑛、风少微、戚少商、凤朝歌、柳沧海、墨不逆、公孙大娘、叶雪青、叶问舟）。
- 3 个相同棋子合成升星（1→2→3 星）。
- 职业定位：近战战士 / 迅捷（强攻）射手 / 近战刺客 / 远程输出（谋士）/ 力士（前排）/ 辅助等。
- 等级提升可上阵更多棋子，人口上限 9～10 级（赛季会调整，如"等级 10 强度上限提升"）。

### 3.2 羁绊（两套体系并行）
- **势力/门派羁绊**：明昭侯府、四大名捕、天野盟、怒潮阁、凤城、连云寨、镜天阁、非命阁、武林风云录、初涉江湖、魔天、九光寒林……（随赛季/联动增删，如甄嬛传联动、明星棋子回归）
- **职业羁绊**：射手、刺客、谋士、力士、血甲、御剑、重鸣、浴火、战士、辅阵……
- 每个羁绊有分层效果（2/3/4/5… 层级数值递增），是阵容强度的核心。

### 3.3 装备
- 品阶：白 → 紫 → 独珍 → 橙武；每个棋子最多穿 3 件；战斗开始后不可卸下。
- 特殊装备：
  - **转职装备（万职书）**：给棋子附加一个羁绊，阵容转型的关键道具；
  - **专属令牌**（如四大名捕的「神侯令」）：羁绊专属强化道具；
  - 例：傲雪铠、苍玉腕、血奠枪、两仪佩等。

### 3.4 心悟（= 金铲铲的"强化符文"）
- 在特定回合（2-1、3-2…）三选一，类型分：羁绊专属心悟、转职类、经济类、装备/属性类。
- 通用优先级共识：专属/转职 > 经济 > 属性。非常适合做"心悟图鉴 + 推荐标签 + 阵容关联"。

### 3.5 对局流程与经济
- 开局前 3 场为人机局；有选秀/转盘环节（血量低者优先拿棋子/装备）；对局中有场景交互（触碰球拿奖励）。
- 金币经济：连胜/连败收益、刷新商店、50 金吃利息、攒钱升人口等经典自走棋运营。
- 有段位机制与赛季结算。

> 数据模块结论：需要 建模 5 张核心表 —— `棋子`、`羁绊`、`装备`、`心悟`、`阵容`，外加 `版本更新记录`。

## 4. 我们的功能清单（按优先级）

### P0 · 首版核心（MVP，先解决"查"）
1. **棋子图鉴**：按费用 / 职业 / 羁绊 / 关键字筛选；详情页含立绘、技能说明、羁绊、推荐装备与推荐阵容跳转。
2. **羁绊图鉴**：势力羁绊 + 职业羁绊两栏，展示各层级效果数值、同羁绊棋子列表。
3. **装备图鉴**：品阶筛选（白/紫/独珍/橙武）、转职装备与专属令牌特殊标记、适配棋子推荐。
4. **心悟图鉴**：按类型（专属/转职/经济/属性）分组，标注强度评级与适用阵容。
5. **阵容推荐**：
   - 首页按赛季展示强势阵容榜（S/A/B 分级 + 标签：魔天、凤城、血甲、连云寨…）；
   - 阵容详情页：站位图（前排/后排格子示意）+ 棋子构成（几费几星）+ 主 C 装备 + 心悟选择优先级 + 运营节奏（几级 D 牌 / 什么时候升人口 / 前期过渡）。
6. **版本适配基座**：所有数据走云端 JSON/云数据库，支持赛季切换与热更新（绝不硬编码进小程序包，版本更新太频繁）。

### P1 · 第二期（解决"用"）
7. **阵容模拟器**：从图鉴选棋子上场（1～10 人口），实时计算已激活羁绊层级与剩余缺口。
8. **全局搜索**：一个搜索框直达棋子/羁绊/装备/心悟/阵容。
9. **我的收藏**：收藏阵容与棋子，"我的棋子池"快捷入口。
10. **D 牌概率表**：等级 → 各费棋子刷新概率速查。
11. **版本更新日志页**：聚合官方公告（平衡调整、新棋子、联动）。
12. **阵容分享卡片**：生成图片卡片供微信群分享（替代游戏内阵容码导入的传播方式）。
13. **历史赛季归档查询**：赛季切换器，可回看往赛季的棋子/羁绊/阵容快照（首版只录入当前赛季，但数据模型从第一天就带 `season` 字段，赛季更替时归档不删除）。

### P2 · 远期（解决"留"）
14. UGC 阵容投稿 + 点赞/评论（做"侠棋社区"雏形）。
15. 对局记录手动打卡（记录战绩、阵容、名次，统计吃鸡率——无官方 API 的替代方案）。
16. 开黑组队 / 玩家圈。
17. "AI 军师"：输入当前拿到的棋子/心悟，推荐过渡方向与成型阵容（离线规则引擎或 LLM 接口）。
18. 屠龙刀式增值：伤害计算器、强势阵容周报推送（订阅消息）。

## 5. 页面结构草案（4 个 Tab）

```
Tab1 阵容      赛季阵容榜（S/A/B）→ 阵容详情（站位图/构成/装备/心悟/运营）
Tab2 图鉴      顶部分段：棋子 | 羁绊 | 装备 | 心悟（二级页为详情）
Tab3 工具      模拟器 | D牌概率表 | 更新日志
Tab4 我的      收藏 | 对局记录 | 反馈 | 关于
```

## 6. 技术与架构建议

- **前端**：微信原生小程序或 Taro/uni-app（若有跨端打算）。UI 参照金铲类助手的"深色 + 金色武侠"风格，贴合逆水寒美术调性。
- **后端**：首版直接用**微信云开发**（云数据库 + 云函数 + 云存储），免运维、免备案域名；数据表：`pieces` / `bonds` / `equipments` / `augments` / `comps` / `patch_notes`，均带 `season` 字段。
- **内容后台**：做一个简易管理端（或先用云开发控制台 + JSON 导入脚本）维护数据；每个赛季更新时只需改数据不发版。
- **数据来源流程**：官方公告（网易大神、逆水寒官网、大神 App）+ 社区整理（巴哈姆特、NGA、B 站攻略）人工核对录入 → 沉淀为结构化数据。

## 7. 合规与风险提示

1. **名称与商标（已定名「逆水小助手」，2026-10-28）**：名称含"逆水"二字，指向网易《逆水寒》IP，微信小程序命名审核存在被判定侵犯他人商标/造成混淆而驳回的风险。需准备备选名（侠棋小助手 / 侠棋图鉴）；无论用哪个名，页面内都要标注"非官方工具，数据仅供参考，版权归网易所有"。
2. **类目审核**：微信小程序选择"工具 > 信息查询"或"游戏 > 攻略"类目，纯查询工具类一般可过审；注意不要抓取/二次分发受版权保护的立绘原素材（用自绘或经授权素材，或仅文字数据）。
3. **数据时效**：赛季更新频繁是最大维护成本，MVP 阶段就要把"数据与代码分离"作为硬性架构约束。
4. **接口依赖**：不要设计任何依赖"游戏内导入/悬浮/战绩 API"的功能，目前均不存在。

## 8. 已确认决策（2026-10-28）

| 问题 | 决策 | 落地影响 |
|---|---|---|
| 首版数据范围 | 只覆盖**当前赛季**；历史赛季数据**保留查询** | MVP 只录入当前赛季；所有数据表带 `season` 字段，赛季更替归档不删除；P1 上线赛季切换器 |
| 阵容内容最初来源 | **自己整理** | 冷启动不依赖 UGC 投稿，按 §6 来源流程人工核对录入 |
| PC 端官网 / H5 镜像 | **暂时不做** | 站外传播全部走小程序分享卡片 |
| 小程序名称与品牌 | **逆水小助手** | 注意 §7 命名审核风险，备选名待命 |
