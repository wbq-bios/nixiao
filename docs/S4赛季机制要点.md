# S4 赛季「九霄龙吟」机制要点

> 来源:逆水寒手游官方公众号文章《策划终于开窍了:好东西,就得让玩家自己挑》
> https://mp.weixin.qq.com/s/-kJuJsSIKiokIU5VASjLlA(2026-10-29 抓取)
> 用途:S4 数据录入 / OCR 清洗 / 模拟器与图鉴开发的对齐参考。本文只记事实与对我方工具的影响,细节以游戏实装为准。

## 1. 赛季基本情报

- **S4 赛季名:「九霄龙吟」**(pack.js 赛季条目启用时用此名)
- **S3 普通模式保留一个月并行开放**:S4 上线后 S3 数据不下架,归档可查
  → 我方对策:已录入的 S3 全量数据(棋子 60 / 羁绊 22 / 装备 156 / 心悟 206)保持可查,赛季切换走既有归档逻辑

## 2. 全新机制:「龙图秘宝」

野怪回合替换为自由选宝。六种宝箱:**棋子、心悟、特殊道具、金币、装备、龙魂**;上层固定类型物品、下层随机物品,金币采购,**价格随购买次数上涨**。

### 棋子宝箱(按回合阶段定向)

| 阶段 | 内容 |
|---|---|
| 2-7 初步定阵 | 2 星 1~3 费、1 星 4~5 费 |
| 3-7 巩固/变数 | 已有棋子 + 随机低星高费 / 高星低费 |
| 4-7 补强上限 | 已激活羁绊的棋子 + 强力 5 费 |

### 其他宝箱

- **装备宝箱**:前期拿神器定阵,后期补强
- **心悟 / 特殊道具宝箱**:俗称"赌狗宝箱"(结果随机性大)
- **金币宝箱**:金币、经验、刷新次数

## 3. 开局阵容三选一 + 惊喜锦囊

- 开局 3 回合野怪替换为**初始阵容三选一**
- 概率出现第四选项**「惊喜锦囊」**:放弃开局阵容,换取若干回合后的强力加成(高费卡、金色心悟、橙武;例:2-7 回合解锁随机橙武)

## 4. 龙魂神器

- 5-7 回合出现龙魂宝箱
- 示例「**龙骨王座**」:携带者占用所有剩余人口,每占 1 人口自身与队友变强,占满时全属性额外 +10%

## 5. S4 新羁绊名单(OCR 录入清单)

习艺生、汪汪队、拜火教、逐浪潮生、天下双势(S3 延续)、谪仙雷吟、连云寨、自在门、神侯府、关山剑影

> 特性提示:习艺生=成长/奇遇类;汪汪队=骨气/屈服(可使其他棋子化身汪汪)

## 6. 数值与规则变化(影响数据解析)

| 变化 | 对我方的影响 |
|---|---|
| **5 费卡数量 10 → 9** | odds 概率表录入真实数值时按新规则;现有 odds 表是占位数据,S4 录入时重做 |
| 棋子普攻不再回复内力,改为每秒自然回内力 | 棋子技能/属性描述 OCR 时的新表述 |
| **荆棘** 入全属性范畴:每 2 秒对当前目标造成伤害 = 承受初始伤害的百分比,不触发会心/吸血 | S4 描述文本高频新词条,OCR 归一化词表预留 |
| 新增**破防伤害**:伤害(算防御和增减伤)/ 破防伤害(无视防御,算增减伤)/ 真实伤害(无视防御和增减伤) | 同上;三层伤害体系词条会出现在装备/羁绊/心悟描述中 |
| 高级同心镜可直奔三星五费 | 心悟图鉴该词条的关键知识点,描述录入别截断 |
| 伤害统计页用颜色区分会心/荆棘/吸血 | 不影响我方工具 |

## 7. 对工具的落地清单(待办对照)

1. **S4 数据录入**(对应总待办 1):截图 → OCR(SEASON=S4)→ s4_convert 按 S3 同流程 → 录入时赛季名用「九霄龙吟」
2. **OCR 清洗预留**:荆棘 / 破防伤害 / 龙图秘宝 / 惊喜锦囊 / 龙魂 等新词条进归一化与人工修正词表(MANUAL_*)
3. **odds 真实数值**:S4 概率表按"5 费 9 张"新规则录入,替换占位数据
4. **模拟器注意**(归另一会话):S4 有选宝/锦囊/龙魂变量,S3 版摆棋推演逻辑不完全适用
5. **图鉴候选新分类**:龙魂神器、特殊道具(等 S4 实装数据再定表结构)
6. **赛季切换**:数据录入完成后按 `backend/sql/s4_launch.sql` 流程启用 S4 赛季条目(S3 转归档保留)
