## 一、项目定位

服务《逆水寒手游》自走棋玩法「逆水侠棋」的微信小程序工具(名称"逆水小助手"):
**赛前备课 · 局间快查 · 赛后复盘**。参考金铲铲助手类产品,设计语言=浅色宣纸+墨字+古铜金,武侠语感文案。

- 技术栈:微信原生小程序(通用内核+游戏内容包) + Express API + MySQL 8 + OCR 素材图床
- 仓库:https://github.com/wbq-bios/nixiao(public,gh CLI 已登录 wbq-bios)
- 架构原则:**通用内核+游戏内容包**——页面/组件禁止写死游戏专名,换游戏=换 `games/<gameId>/` 内容包

## 四、接口与数据约定

| 接口 | 说明 |
|---|---|
| POST /api/auth/login | deviceId(或 wx code)→ HMAC token;未配 WX_SECRET 时 openid=dev_* |
| GET /api/content/:gameId?season=&version= | 整包内容,版本号短路热更新 |
| /api/user/favs · /api/user/sims · /api/vote | 收藏/摆棋存档(50条上限)/一票制赞踩(3s频控) |
| POST /api/admin/import | X-Admin-Token;按行自带 season 幂等导入 |
| GET /art/thumb/<w>/… · /art/icon/<w>/… · /art/… | 立绘缩略图(cover) / 图标(trim颜色边界+contain) / 原图 |

- 内容表 `_key`={gameId}:{season}:{业务键},doc JSON 与 `games/xq/data/*.js` 同构;**同名字段跨赛季并存,一切查询按赛季过滤**
- 图标字段须带目录前缀(羁绊图标/xxx.png);立绘路径由 converter fix_art() 自动修复
- 小程序强约束:读数据走 `core/format.js`(pieceOf 已赛季感知);写操作走 store/api,失败静默降级

## 五、渲染器三大坑 + 调试方法论(血泪,勿踩)

1. **wxss rpx 尺寸部分环境不生效**(连内联 rpx 都不行)→ 关键尺寸 JS 按屏宽算 **px 内联**
2. **grid 容器里放 `<button>` 破布局**(快捷入口变 2 列)→ 用 `<view>`
3. **scroll-view 内容不吃宿主 flex** → inline-block + nowrap(横滑标准解)
4. `lazy-load` 在"页面纵滚+横向 scroll-view"嵌套里不触发 → 缩略图场景去掉 lazy-load
5. 小头像裁剪:用 **background cover + position top**(头部优先识别人物;aspectFill 居中会裁到身子);图形类图标用后端 **trim 颜色边界 + contain**(不裁图形)
6. WXSS **中文类名选择器过不了编译**(.rar.白 ✗);数据里的中文值做类名须映射成 ASCII
7. `wx:for` 嵌套漏 `wx:for-item` → 内层绑定全 undefined(格子在、内容空),极像"图没加载"——**先查绑定再查网络**

调试工具链:
- `pipeline/e2e_ui.js`:自动化走查(切 Tab/截图/采 Console),截图在 pipeline/out/
- 编译器直跑:`D:\微信web开发者工具\resources\app.asar.unpacked\node_modules\wcc-electron\wcsc.exe`(中文路径先拷走)
- `pipeline/dbview.js`:只读数据库网页浏览器(:3001)
- 后端日志字节级解剖 + python urllib 构造 URL(**手打中文 URL 会打错字,必须脚本编码**)
- 开发者工具热更新偶发不生效 → `cli.bat auto --project ... --auto-port 9420` 强制重编;顽固时清 WeappCompileCache
