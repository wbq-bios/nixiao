## 4. 工程与运行

- 结构：`miniprogram/`（core 内核 + games/xq 内容包 + pages + utils/api.js）、`backend/`（Express，13 表）、`pipeline/`（OCR 转换 / e2e 走查 / 素材与图标生成）、`docs/`、`设计稿/`
- 启动：`backend/dev-start.cmd`（绿色版 MySQL + Node + API）；小程序在开发者工具导入 `miniprogram/`（勾选「不校验合法域名」）
- 自动化调试：`cli.bat auto --project ... --auto-port 9420 --trust-project` 后 `node pipeline/e2e_ui.js`
- 常用脚本：`pipeline/s3_convert.py`（OCR→数据）、`pipeline/sync_bond_icons.ps1`（彩色羁绊图标同步到图床）、`pipeline/gen_icons.py`（线性图标）、`pipeline/gen_mock.py`（设计稿）
- 后端关键接口：`/api/content/:gameId`、`/api/comps/stats/:gameId?season=`（赞踩 + 收藏聚合）、`/api/vote`（一票制 + 3s 频控）、`/api/user/favs`、`/api/user/sims`、`/art/*`
