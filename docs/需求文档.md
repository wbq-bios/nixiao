## 1. 产品概述

| 项 | 内容 |
|---|---|
| 定位 | 逆水侠棋 · 赛前备课 / 局间快查 / 赛后复盘工具（非官方） |
| 平台 | 微信小程序（原生 + 云开发） |
| 架构 | 通用内核 + 游戏内容包（可复用到其他自走棋） |
| 核心 | 5 Tab：首页 / 阵容 / 摆棋 / 图鉴 / 我的；一切数据以「赛季」为维度 |
| 变现 | 信息流 banner 广告位预留（后台开关） |

## 3. 赛季体系（贯穿全站）

```mermaid
flowchart TD
    Start["任意页面顶部赛季入口行<br/>『当前赛季名 | 切换赛季 ›』"] --> Open["弹出赛季列表弹层"]
    Open --> Pick{"选择赛季"}
    Pick -->|"当前赛季行"| Stay["无操作（已选中：米黄底金边）"]
    Pick -->|"归档赛季行"| Confirm["全局切换 curSeason<br/>（归档数据只读）"]
    Confirm --> Refresh["联动刷新：首页/阵容库/图鉴/摆棋"]
    Refresh --> ResetMe["『我的』档位重置为『当前赛季』"]
    Stay --> Close["关闭弹层"]
    ResetMe --> Close
```

**规则**：所有数据集合读写自动注入 `season` 字段；赛季更替时旧数据归档不删除，弹层可随时切回查看。

### 4.1 点赞/踩 状态机（单人一票制）

```mermaid
stateDiagram-v2
    [*] --> None
    None --> Up : 点赞（+1）
    None --> Down : 点踩（+1）
    Up --> Down : 点踩（换边：赞−1 踩+1）
    Down --> Up : 点赞（换边）
    Up --> None : 再点赞（取消）
    Down --> None : 再点踩（取消）
    note right of Up : 净分 = 赞 − 踩，实时计入「口碑」排序，云端按 openid 去重防刷
```

### 5.1 棋盘交互总路由


### 5.3 棋子设置弹窗（点棋子）


## 8. 云端数据流（正式版）

```mermaid
sequenceDiagram
    participant U as 用户
    participant MP as 小程序
    participant CF as 云函数
    participant DB as 云数据库
    U->>MP: 任意读操作
    MP->>CF: 请求（自动注入 gameId + season）
    CF->>DB: 按复合条件查询
    DB-->>MP: 数据（赛季热更新，不发版）
    U->>MP: 点赞/踩
    MP->>CF: vote(compName, value)
    CF->>DB: 查 openid 是否已投
    alt 已投同向
        CF-->>MP: 取消该票
    else 已投反向
        CF-->>MP: 换边（赞−1 踩+1）
    else 未投
        CF-->>MP: 写入新票
    end
    U->>MP: 保存摆棋快照
    MP->>CF: user_sims 写入（board/stars/items/mainC/season）
    CF-->>MP: OK → 『我的』列表可见
```

## 10. 非功能需求

| 类 | 要求 |
|---|---|
| 合规 | 名称备选「侠棋小助手」防审驳回；全站非官方免责声明；零游戏立绘（印章字头像） |
| 性能 | 数据全云端热更新；图片懒加载；动画仅 transform/opacity |
| 可复用 | 组件/页面禁止游戏专名，文案走 pack.terms；换游戏=换内容包 |
| 降级 | 减弱动效模式下移除装饰动效、保留终态；离线只读缓存最近赛季数据 |
