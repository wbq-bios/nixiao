# 小程序注册与权限申请指南

> 适用项目：逆水小助手（逆水侠棋助手小程序）
> 更新日期：2026-10-28 · 主体类型：**个人**
> 结论先行：**注册账号 → 拿 AppID → 开云开发 → 填隐私指引 → 备案 → 提审**。备案最长约 20 个工作日，建议今天就启动注册。

---

## 0. 你需要准备的材料（全程仅能本人操作）

| 材料 | 用途 | 备注 |
|---|---|---|
| 一个新邮箱 | 注册账号 | 未注册过微信公众平台（公众号/小程序都算） |
| 本人身份证 | 主体登记 + 备案 | 个人主体 = 管理员本人 |
| 本人手机号 | 短信验证 + 工信部核验 | 保持畅通 |
| 本人微信 | 扫码人脸核验 | 注册与备案各需一次 |
| 小程序头像 | 账号资料 | 项目里已有 `docs/1793147352429.jpg` 可直接用 |
| 备选名称 ×2 | 名称可能被占用或驳回 | 见 §2 |

## 1. 注册小程序账号（约 15 分钟）

1. 打开 [微信公众平台 mp.weixin.qq.com](https://mp.weixin.qq.com) → 右上角「立即注册」→ 选「**小程序**」。
2. 填邮箱 + 密码 → 去邮箱激活。
3. 主体类型选「**个人**」→ 填写管理员身份证信息、手机号 → **微信扫码人脸核验**。
4. 完成「信息登记」（名称、简介等，见下节），提交后进入小程序后台。

> 💡 只是先开发调试的话，也可以用「测试号」（注册页有入口，免注册），但测试号**无法用云开发正式环境、不能发布**，建议直接注册正式账号，一步到位。

## 2. 账号资料填写（定案信息照抄）

| 项目 | 填写内容 | 说明 |
|---|---|---|
| 名称 | **逆水小助手** | 不含"逆水寒"三字，规避网易商标；被占用依次备选：侠棋小助手 → 侠棋图鉴 |
| 简介 | 逆水侠棋玩法图鉴与阵容工具：棋子/羁绊/装备/心悟查询、阵容推荐、摆棋模拟 | 别出现"逆水寒"字样 |
| 头像 | `docs/1793147352429.jpg` | 建议输出 144×144 |
| 服务类目 | **工具 → 信息查询**（备选：工具 → 效率） | 个人主体可选项有限；游戏攻略/图鉴类惯例归入"信息查询"。**切勿选游戏类目**（需版号资质，必驳回） |

> 名称审核 1~3 个工作日。名称含"小助手"可能触发与官方产品混淆的驳回，若两次被驳，直接用「侠棋图鉴」。

## 3. 拿到 AppID 并接入工程

1. 后台「开发 → 开发管理 → 开发设置」→ 复制 **AppID**。
2. 打开 `miniprogram/project.config.json`，把第 3 行 `"appid": "touristappid"` 替换为正式 AppID。
3. 微信开发者工具重新导入 `miniprogram/` 目录（用注册小程序绑定的微信登录工具）。

## 4. 成员管理（可选但建议）

后台「成员管理」：添加**体验成员**（用真机预览体验版）最多 15 人；个人主体**不能**添加项目开发者以外的运营者配置（无此权限分层，够用）。

## 5. 云环境开通（Phase 1 的前置，两条路线二选一）

**路线 A：微信云托管（当前后端方案的推荐部署方式）**
backend/ 是 Express + MySQL，本地已跑通；上线时用 [微信云托管](https://cloud.weixin.qq.com/cloudrun) 部署（自带 MySQL，按量计费，有小额免费额度）。
- **服务端免备案**（托管在微信体系内，无需配置 request 合法域名）；
- 但注意：免备案的只是**服务器**，**小程序账号本身仍要备案**（见 §7，两回事）。

**路线 B：微信云开发（原《后端设计》方案，保留为远期选项）**
1. 开发者工具顶部「云开发」→ 开通 → 创建单环境（如 `xq-prod`），记下环境 ID。
2. **费用**：「基础套餐 + 按量付费」，基础套餐**约 19.9 元/月**，新用户免费 1 个月；以 [云开发官网](https://cloud.weixin.qq.com/cloudbase) 为准。
3. 建齐 11 个集合（内容 8 + 用户 3 + config），确定性 `_id` 规则照《后端设计》执行，云函数 5 件上传部署。

两条路线客户端都走 `utils/api.js` 的接口封装，切换成本低；**当前按路线 A 推进**。

## 6. 用户隐私保护指引（提审前必填，不填必拒）

后台「设置 → 基本设置 → 服务内容声明 → **用户隐私保护指引**」：

- 本项目实际收集：**微信openid**（登录标识、点赞/收藏/存档去重）、**用户主动保存的阵容数据**（收藏与摆棋存档）。
- 用途照实写："用于账号标识、防重复点赞、云端保存用户的收藏与阵容存档"。
- 不用 getUserProfile/位置/手机号就**不要声明**——声明了却没用到，或用到了没声明，都会被拒。个人主体拿不到手机号权限（企业专属+付费组件），别申请。
- 若后续在"我的"页做微信头像昵称填写（头像昵称填写能力对个人开放），需补声明并接 `wx.onNeedPrivacyAuthorization` 授权弹窗。

## 7. 小程序备案（上线硬门槛，最耗时的环节）

依据工信部规定，**未备案不能发布**。入口：后台「设置 → 基础设置 → 小程序备案」，全程线上：

1. 填写备案信息（主体 + 小程序 + 负责人，个人主体用身份证 + 人脸核验）；
2. 平台初审（1~2 个工作日）；
3. 收到工信部短信后 **24 小时内**完成核验；
4. 省通管局审核，**最长 20 个工作日**，各省不同、无法加急；
5. 备案成功拿备案号。

注意：

- **预留 1 个月**，建议注册完账号立刻启动备案，与 Phase 1/2 开发并行；
- 备案通过后，首页底部须悬挂备案号（如"京ICP备XXXXXXX号-X"），代码里给首页 footer 预留一行；
- 备案主体、类目必须与实际内容一致（工具/信息查询，别让审核在页面上看到"代练""交易"等字样）。

## 8. 各能力与权限对照（哪些要申请、哪些拿不到）

| 能力 | 需要什么 | 个人主体结论 |
|---|---|---|
| wx.login / openid | 无需申请 | ✅ 直接用 |
| 分享卡片（onShareAppMessage） | 无需申请 | ✅ 直接用（站外传播方案即此） |
| 云开发 | 开通付费套餐 | ✅ 开通即用 |
| 头像昵称填写 | 隐私指引声明 | ✅ 可用 |
| 广告（流量主） | 累计 UV ≥ 1000，后台「推广 → 流量主」开通 | ✅ 达标后开；首页/图鉴底部广告位已预留，届时换真 ad 组件 |
| 微信支付 | 企业主体 + 认证 | ❌ 拿不到（MVP 也不需要） |
| 手机号快速验证 | 企业主体 + 付费 | ❌ 不需要 |
| 微信认证 | 个人主体不支持 | ❌ 不影响上述功能 |

## 9. 提审发布（Phase 3）

- 代码上传 → 后台「版本管理」提交审核：类目与页面内容一致；截图用自己做的界面，**不要用网易官方美术素材/图标**（版权驳回风险）；简介与名称里避开"逆水寒"。
- 演示数据阶段先别急着提审，等 Phase 2 真实数据录入完、图鉴和摆棋都可用再上（首审印象分重要，被拒记录会影响后续审核宽严）。
- 审核被拒看清楚"具体类目/具体页面"的驳回原因对症修改，别盲改。
